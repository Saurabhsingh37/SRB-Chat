# 💬 SRB Chat

>
> A modern, real-time chat application built with Next.js.

## ✨ Features

* 🔐 User authentication
* 💬 Real-time messaging
* 👥 One-to-one conversations
* 🟢 Online/offline status
* ⌨️ Typing indicators
* ✓ Read receipts
* 🔍 User search
* 📱 Responsive & mobile-friendly UI
* 🖼️ Image and file sharing
* 🔔 Message notifications

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **JavaScript**
* **Tailwind CSS**
* **PostgreSQL**
* **Real-time communication**
* **Git & GitHub**

## 🚀 Getting Started

```bash
git clone https://github.com/your-username/srb-chat.git
cd srb-chat
npm install
npm run dev
```

Open **http://localhost:3000** in your browser.
